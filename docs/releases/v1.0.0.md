# MindKit v1.0.0

First Android release of MindKit, an on-device toolkit for writing, images, audio,
translation, and developer utilities. It includes local searchable history and
one-time handoffs between tools.

Install the attached `MindKit-v1.0.0.apk` on Android 8.0 or later. This is a
universal APK containing ARM and x86 libraries, so the download is about 116 MB.

Gemini Nano features depend on the device, Android's AICore services, language,
and installed models. The app shows availability and download requirements for
each feature. On-device model inference and microphone behavior still need
verification on compatible physical hardware.

The APK is signed with the MindKit release key (APK Signature Scheme v2 and v3).
SHA-256: `CAF5C2C5453CB2246FF0CDB1FD85E43AAD1E35374DBBC83F3DFBB6D40AAC06A0`

Verification before release: 487 JVM tests passed with one documented skip;
46 Android emulator tests passed; debug and release builds passed; Android lint
reported zero errors and four dependency-update notices. A separate real
process-death check verified that the latest pending share survives restoration
and dismissed shares do not reappear.
The exact signed APK was installed and cold-launched successfully on an API 36
Android emulator, with MindKit remaining in the foreground and no app crash.
