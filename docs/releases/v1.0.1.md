# MindKit v1.0.1

This update makes the home screen's task shortcuts match the features actually
available on the device. When on-device writing or image tools are unavailable,
the shortcuts now offer translation or text extraction instead. An unavailable
audio tool is no longer advertised.

The home screen also adapts to narrow displays and larger accessibility font
settings: shortcut labels remain readable, the header can grow with its content,
and the navigation label stays visible at very large text sizes.

Install the attached `MindKit-v1.0.1.apk` on Android 8.0 or later. It is a
universal APK for ARM and x86 devices, signed with the same MindKit release key
as v1.0.0. Existing installations can update without losing app data.

Gemini Nano features still depend on the device, AICore services, language,
and installed models. Physical-device testing of model inference and microphone
behavior remains outstanding.

installed and launched on an API 36 emulator without a crash.
